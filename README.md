# Data Science Dashboard Project

This is a project to build a dashboard in a business environment.
Simulated data is provided


## Prerequisites

The following libraries are required:  
- scikit-learn==1.5.2  
- python-fasthtml==0.8.0  
- matplotlib==3.9.2  
- scipy==1.14.1  
- numpy==2.1.2  
- pandas==2.2.3  

To install these libraries execute:  
`pip install -r requirements.txt`

Create a virtual environment with Python version 3.10 or higher
```
python3 -m venv venv
source venv/bin/activate
```

------------------------------
### python-package/  
This directory contains a `setup.py` file for building a Python package and a `employee_events/` subdirectory that contains all source code for the Python package.

### report/  
This directory contains the following files for building a FastHTML dashboard:
- `dashboard.py`
- `utils.py`   

### tests/
This directory contains the `test_employee_events.py` file with all the Python tests for the Python package.
